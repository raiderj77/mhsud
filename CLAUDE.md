# MindCheck Tools

Read `AGENTS.md` before doing any work.

`AGENTS.md` is the single MindCheckTools source of truth for product safety, instrument rights, clinical language, privacy, accessibility, security, SEO, AEO, GEO, AI, monetization, automation, repository simplicity, and release gates.

When an older file, prompt, agent, command, or portfolio standard conflicts with `AGENTS.md`, follow `AGENTS.md`.

Project basics:
- Next.js App Router
- TypeScript
- Tailwind CSS
- Vercel
- npm
- `main` auto-deploys, so use a branch/PR and pass the required tests before merge

Never:
- change validated questionnaire wording or scoring without approved evidence
- diagnose users from screening results
- send screening answers/scores to analytics, ads, email, referrals, logs, or remote AI
- re-enable display advertising
- weaken crisis, privacy, accessibility, security, or rights controls
- push consequential untested changes directly to main
